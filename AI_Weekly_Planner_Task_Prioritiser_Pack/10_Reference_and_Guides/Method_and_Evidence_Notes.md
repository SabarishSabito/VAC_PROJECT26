# Method and evidence notes

## Source brief
The required deliverables and constraints in this pack are based on `AIDS-75.pdf`, page 29, CAPSTONE 33 — AI Weekly Planner and Task Prioritiser:
- task list of 25 tasks with deadlines and effort levels;
- prioritisation using a method such as Eisenhower or time-blocking;
- comparison of three AI tools and checks for impossible schedules;
- implementation in Google Calendar or Todoist;
- one-week follow-through and completion rate;
- one-page weekly template;
- comparison with usual planning method;
- at least six AI skills from Topics 1–9;
- at least four tools;
- final submission includes task list, three plans, final plan, completion log, template, prompt library, verification report, before/after analysis, final demo.

## Evidence rules
- Preserve raw model outputs unchanged before analysing them.
- Use identical input data and prompt across the three tools.
- Note model/version if visible and date/time of run.
- Record only actual completion data.
- Clearly label assumptions and limitations.
- If no prior baseline data exists, do not fabricate it.

## Method note
The sample list and day-level plan in this pack are examples to help start the project, not facts about the student's actual deadlines or schedule. Replace them before treating the plan as final.
