# One-week execution and completion log

The experiment week in the sample files is 26 Oct–1 Nov 2026. Change it if needed. The week has not happened yet at pack creation, so no completion results are prefilled.

Each evening, record planned duration, actual duration, status, whether completed by the real deadline, interruptions and carry-forward action. Do not mark a task complete unless it was actually completed.

Metrics:
- Task completion rate = completed tasks / tasks planned for the week × 100.
- On-time completion rate = tasks completed by deadline / tasks with deadlines during the measurement window × 100.
- Estimate error = actual hours − estimated hours (calculate only when both are recorded).
- Carry-forward count = tasks not completed and moved to a later period.

A task can be completed but late; record completion and on-time status separately. Explain any task removed or scope reduced.
